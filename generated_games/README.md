These games are included intentionally to show where the pipeline currently stands: the architecture, game logic, visual design, and mechanics are fully generated — the game is built at ~95%. What remains is a fine-tuning problem: the LLM occasionally produces a variable name that doesn't match the one declared in the ENGINE section, causing a runtime crash that a targeted one-line fix would resolve.

Closing this last 5% requires running hundreds of generation iterations across all genre templates to extract the recurring patterns and encode them as additional linter rules and auto-fix cases. This is the exact purpose of the gap analysis workflow already in place — it simply needs more compute budget to run at scale.

Gem Cascade shows what the output looks like when everything aligns.
